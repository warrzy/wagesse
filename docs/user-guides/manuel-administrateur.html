WAGESSE

Manuel administrateur

Préproduction https://preprod.wagesse.fr, commit 627cb4fc0fcd014e8743db2249b1887fe71dd173, 7 novembre 2026. Ce manuel ne contient aucun mot de passe. L'administrateur déjà en place n'est ni lu ni modifié.

1. Entrer dans l'administration

Objectif. Ouvrir le tableau de bord du rôle ADMIN.

  1. Ouvrir la page Connexion.
  2. Saisir le numéro et le mot de passe du compte administrateur. Le champ mot de passe reste masqué.
  3. Contrôler que l'adresse devient /admin.

Après une connexion réussie, l'application envoie l'administrateur vers /admin, le client vers /dashboard/client et le transporteur vers /dashboard/trucker. L'écran de code SMS n'est plus imposé à ce moment.

Erreur fréquente. Un client ou un transporteur qui ouvre /admin ne reçoit pas les données d'administration. L'API répond HTTP 401.

Le cycle du 7 novembre a ouvert une session avec l'administrateur de recette 78003021, distinct de l'administrateur initial. Le tableau de bord, les utilisateurs, les commandes, les forfaits et les journaux ont répondu HTTP 200.

2. Valider un paiement manuel

Objectif. Attribuer une seule fois les crédits d'une commande déjà créée.

  1. Laisser le client enregistrer la commande. Tant qu'elle est en attente, son solde ne change pas.
  2. Ouvrir la commande dans l'administration et lire la référence, le pack et le compte.
  3. Valider une fois. Le solde augmente du nombre de crédits du pack.
  4. Valider de nouveau la même commande. La réponse indique que l'opération est déjà traitée et le solde ne bouge pas.
  5. Refuser une autre commande avec un motif d'au moins trois caractères. Le solde ne change pas.

Ce scénario est PASS sur la préproduction. Le premier pack du catalogue a servi d'exemple. Aucun paiement PayDunya n'a été lancé. Le mode annoncé par /api/payments/mode est MANUAL.

Erreur fréquente. Croire que l'enregistrement de la commande a déjà crédité le portefeuille.

3. Téléphone des comptes de recette

En préproduction seulement, l'administrateur peut marquer comme vérifié un compte fictif dont le numéro commence par 7800 et dont le nom contient « Recette ». Un administrateur n'est pas accepté. La réponse ne contient pas de code. Un client qui appelle cette route reçoit HTTP 401.

Cette route doit rester fermée en production. Le contrôle deploy/production/assert-env.mjs refuse un fichier d'environnement qui la laisserait ouverte.

3 bis. Compte sans SMS

Lorsque la vérification SMS n'est pas exigée, un client achète et débloque sans code. Le solde et la validation manuelle ne changent pas. Un mot de passe oublié n'est pas envoyé à un numéro jamais vérifié. L'administrateur peut définir un nouveau mot de passe après un contrôle d'identité réalisé en dehors du numéro. Le guide de réactivation est docs/security/REACTIVATION_SMS.md.

4. Ce que l'administrateur ne trouve pas encore

Certains écrans du menu affichent « en cours de construction » : rôles, contenus, matériaux, promotions, types de camions. Les notifications visibles par un client ne sont pas livrées. Ces manques sont reportés, ils ne bloquent pas le paiement manuel ni la mission.
