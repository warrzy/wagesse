# Marque et mouvement

La pièce jointe du logo n’était pas présente dans l’espace de travail. Le signe utilisé est donc un monogramme W construit avec les couleurs demandées, pas une copie d’un fichier source. Le composant `BrandLogo` lit `public/brand/mark.svg` sur fond clair et `public/brand/mark-light.svg` sur fond sombre. Remplacer ces deux fichiers par le logo d’origine, en gardant le même cadrage carré, met à jour le header, le footer, l’authentification, l’administration, le favicon et les métadonnées.

| Variante | Fichier | Usage |
| --- | --- | --- |
| Fond clair | `public/brand/mark.svg` | Header, formulaires |
| Fond sombre | `public/brand/mark-light.svg` | Footer, administration |
| Icône 32 px | `public/brand/favicon.png` et `app/icon.png` | Favicon |
| Icône 180 px | `public/brand/apple-touch.png` et `app/apple-icon.png` | Écran d’accueil mobile |
| Icône 512 px | `public/brand/mark-512.png` | Métadonnées |

Couleurs : bleu profond `#071D40`, bleu dynamique `#087DD1`, orange `#FF7900`, fond `#F4F8FC`, blanc `#FFFFFF`. La typographie reste Plus Jakarta Sans.
