# Marque et mouvement

Le logo officiel est le fichier fourni : un W bleu traversé par une route, une épingle orange, un véhicule, le mot WAGESSE et un trait orange. Le fond noir a été retiré. Le dessin n’a pas été redessiné.

| Variante | Fichier | Usage |
| --- | --- | --- |
| Fond clair | `public/brand/logo.png` | Header, connexion, inscription |
| Fond sombre | `public/brand/logo-dark.png` | Footer et administration. Le mot est éclairci pour rester lisible sur le bleu profond. Le symbole est inchangé. |
| Icône | `public/brand/mark.png` | Favicon, `app/icon.png`, écran d’accueil mobile |

Couleurs d’interface : bleu profond `#071D40`, bleu dynamique `#087DD1`, orange `#FF7900`, fond `#F4F8FC`, blanc `#FFFFFF`. La typographie reste Plus Jakarta Sans.
